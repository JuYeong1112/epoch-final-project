## 결과 요약 (평가용 50묶음·예비 4묶음은 잠그고, 나머지 72묶음을 조정용/확인용으로 나눠 측정)

| 확인용 기준 | 처음 | 최종 |
|---|---|---|
| 정답 조문이 검색 상위 5개 안 (29건) | 15 (51.7%) | 18 (62.1%) |
| 시험 질문 20건 초안: 자동 점검 통과 / 근거 부족 / 보류 | 15 / 5 / 0 | 18 / 0 / 2 |
| 세 제도 밖 질문 5건 보류 | 0 | 4 |

최종 구성 = 검색 점수 수정(용어사전·제도 감점·제목 가중치 등) + AI가 검색 상위 20개 순서를 다시 정함 + 근거 8개 + 보건복지부 2026 사업안내 3쪽 + 새 지시문(v6) + 범위 밖 보류. 초안은 Claude(claude-opus-5-5) 하위 에이전트가 썼고 외부 AI API는 쓰지 않았습니다. 시험 질문이 29건뿐이라 1건이 3.4%p입니다.

## 실행 (저장소 맨 위 폴더에서)

```bash
cd accuracy_v6
python retrieve_v2.py same          # 스위치를 다 끄면 src/retrieve.py 와 같은지 확인 (다른 결과 0회)
python retrieve_v2.py audit base    # 기준값 (확인용 5개 안 15/29)
python retrieve_v2.py audit v6      # 채택한 검색 설정 (확인용 5개 안 16/29)
python 재순위.py score 확인용        # AI 재순위 전후 (저장된 재순위 결과 사용, 18/29)
python check_citations_v2.py test   # 점검 규칙 시험
python generate_v6.py collect       # drafts_raw/ 의 초안을 모아 drafts_*.csv 로 점검
```

- 잠금 묶음은 `eval/groups/eval_groups.txt` + `eval/groups/eval_group_ids_v1_1.csv`의 용도가 "평가…"인 행(평가용 50 + 평가예비 4 = 54묶음)에서 읽습니다.
- `02_민원질의_상세분류_검증.xlsx`는 유형 분류·안내문 담당의 분류표 사본입니다(시나리오 20건을 유형별로 고를 때 사용).

## 데이터 버전 메모

- 측정은 **고시 24문단판**(G-0025 긴급지원 지원금액 고시가 없던 판)으로 했습니다. 이 저장소의 `data/law/chunks_admrul.csv`는 25문단판이며, 저장소 데이터로 다시 돌려도 검색 숫자(조정용 26/33, 확인용 16/29)는 같습니다(정답 조문 기준이 법령 조문이라). 초안(drafts_*)은 G-0025 없이 만든 것입니다.
- 질의응답·법령 데이터는 저장소 판과 내용이 같습니다(필드 안 줄바꿈 방식만 다름).
