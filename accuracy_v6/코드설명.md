# 코드 설명 (정확도개선 v6)

이 문서는 코드를 읽어 본 적이 없는 사람을 위한 설명입니다. 먼저 용어부터 풉니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 파이썬(Python) | 이 폴더의 `.py` 파일을 실행하는 프로그램 언어 |
| 터미널 | 글자로 명령을 넣는 창. 아래 "다시 실행하는 명령"을 여기에 붙여 넣는다 |
| 함수 | 이름이 붙은 작업 묶음. `def 이름(...):` 으로 시작한다 |
| 검색(retrieve) | 새 질문에 대해 비슷한 질의응답 3건과 근거 조문·고시 문단을 고르는 일 |
| 근거 k개 안 | 고른 근거를 점수 순으로 줄 세웠을 때 위에서 k번째까지 |
| 정답 조문 | 공개 답변에 적힌 근거 조문(qna_all.csv 의 `근거조문` 칸) |
| TF-IDF | 글을 2~4글자 조각으로 잘라, 드물고 겹치는 조각이 많을수록 "비슷하다"고 보는 계산. `sklearn` 의 `TfidfVectorizer` 가 해 준다 |
| 유사도 | 두 글이 얼마나 비슷한지 0~1 사이 숫자. 1에 가까울수록 비슷하다 |
| 조정용 / 확인용 | 값을 고를 때 보는 묶음 / 고른 값을 마지막에 시험하는 묶음 (묶음분할.csv) |
| 잠금 묶음 | 평가용 50 + 평가예비 4. 검색 대상에서도, 점검 대상에서도 뺀다 |
| 스위치(cfg) | 개선을 켜고 끄는 설정값 묶음. `CFG_BASE` = 모두 끔(기존과 같음), `CFG_V6` = 채택한 것만 켬 |

## 1. retrieve_v2.py (검색)

retrieve.py 를 옮겨 온 뒤 바꾼 곳만 보여 줍니다.

### 1-0. 데이터 위치와 잠금

```python
HERE = Path(__file__).resolve().parent
BASE = HERE.parent
LOCK_FILES = [BASE / "eval_groups.txt", BASE / "eval_reserve.txt"]
```
- 1줄: `HERE` = 이 파일이 있는 폴더(정확도개선_v6). `Path(...).resolve()` 는 파일의 전체 경로를 구하는 함수.
- 2줄: `BASE` = 그 위 폴더(정확도개선_작업). 데이터는 원래 자리에서 읽기만 한다.
- 3줄: 잠금 목록 파일 두 개. 평가예비 4묶음도 잠근다.

```python
exclude = self.locked | (exclude_groups or set())
self.qa = [r for r in read_csv(QNA) if r["group_id"] not in exclude]
```
- 1줄: 뺄 묶음 = 잠금 묶음 + (따로 지정한 묶음). `|` 는 두 목록을 합치는 기호.
- 2줄: 질의응답 중 뺄 묶음이 아닌 행만 남긴다. 이렇게 하면 잠금 묶음은 "비슷한 질의"로 절대 나오지 않는다.

### 1-1. 스위치

```python
CFG_BASE = {"dict": False, "fam": 1.0, "title": 0.0, "nb_min": 0.0, "govname": False}
ADOPTED = {"dict": True, "fam": 0.2, "title": 0.3, "nb_min": 0.2, "govname": True,
           "nb_w": 0.5, "purpose": 0.5, "k_nb": 10}
K_EV_V6 = 8
```
- 1줄: 모두 끈 설정. 이때는 retrieve.py 와 결과가 같다(`same` 명령으로 확인).
- 2줄: 실험에서 채택한 값. `fam 0.2` = 다른 제도 조문 점수에 0.2를 곱한다(80% 감점). `title 0.3` = 조문 제목 유사도에 0.3을 곱해 더한다. `nb_min 0.2` = 유사도 0.2 미만인 비슷한 질의는 가점에 쓰지 않는다.
- 3줄: 초안에 넘기는 근거 수를 8개로 한다(1-1 재판정).

### 1-2. 용어사전 적용

```python
def expand_with_dict(q, pairs):
    add = [b for a, b in pairs if a in q and b not in q]
    return q + " " + " ".join(dict.fromkeys(add)) if add else q
```
- 1줄: 질문 `q` 와 사전 `pairs`(시민표현, 법령용어 쌍 목록)를 받는 함수.
- 2줄: 질문에 시민표현이 있고 법령용어는 아직 없으면 그 법령용어를 모은다.
- 3줄: 모은 법령용어를 질문 뒤에 붙여서 돌려준다. `dict.fromkeys` 는 같은 말이 두 번 붙지 않게 하는 방법. 예: "다시 받을 수 있나요" → "다시 받을 수 있나요 긴급지원의 기간".

```python
se = self._scores(self.v_ev, self.m_ev, question)
se_rank = se
if self.dict_pairs:
    se_rank = self._scores(self.v_ev, self.m_ev, expand_with_dict(question, self.dict_pairs))
```
- 1줄: 질문과 모든 근거 문단의 유사도. `_scores` 는 TF-IDF 로 유사도를 계산하는 함수.
- 2줄: 순위에 쓸 점수는 일단 같은 값.
- 3~4줄: 사전이 켜져 있으면, 사전으로 늘린 질문으로 다시 계산한 점수를 순위에 쓴다. 고시 고르는 규칙은 원래 점수(`se`)를 그대로 써서 영향이 없다.

### 1-3. 제도 판별과 감점

```python
def question_family(q):
    hit = [f for f, ws in FAM_WORDS.items() if any(w in q for w in ws)]
    return hit[0] if len(hit) == 1 else None
```
- 2줄: `FAM_WORDS` 에 적힌 제도별 말(예: 기초연금 / 생계급여·수급자 / 긴급지원)이 질문에 있는 제도를 모두 찾는다.
- 3줄: 딱 한 제도만 나오면 그 제도, 없거나 둘 이상이면 `None`(판별 못 함). 판별 못 하면 감점하지 않는다.

```python
if c["fam"] < 1.0:
    fam_q = question_family(question)
    if fam_q:
        for j in total:
            f = law_family(self.ev[j]["name"]) or gov_family(self.ev[j]["name"])
            if f and f != fam_q:
                total[j] *= c["fam"]
```
- 1줄: 감점 스위치가 켜져 있을 때만.
- 3줄: 질문의 제도가 판별됐을 때만.
- 4~7줄: 후보 근거마다 그 근거가 속한 제도를 구하고(`law_family`, `gov_family`), 질문의 제도와 다르면 점수에 0.2를 곱한다.

### 1-4. 조문 제목 가중치

```python
self.v_ti = TfidfVectorizer(analyzer="char_wb", ngram_range=(2, 4), sublinear_tf=True)
self.m_ti = self.v_ti.fit_transform([norm(e["title"]) for e in self.ev])
...
if c["title"] > 0:
    se_rank = se_rank + c["title"] * self._scores(self.v_ti, self.m_ti, question)
```
- 1~2줄: 조문 제목(예: "긴급지원의 기간 등")만 모아 따로 색인을 만든다. `fit_transform` 은 글 목록을 숫자 표로 바꾸는 함수.
- 4~5줄: 질문과 제목의 유사도에 0.3을 곱해 원래 점수에 더한다. 본문이 긴 조문에서 제목의 핵심어가 묻히는 것을 막는다.

### 1-5. 유사도 낮은 이웃 질의 제외

```python
for i in order[:K_NEIGHBOR]:
    if float(sq[i]) < c["nb_min"]:
        continue
```
- 1줄: 가장 비슷한 질의 5건을 차례로 본다.
- 2~3줄: 그 질의의 유사도가 0.2보다 낮으면 건너뛴다(그 질의가 인용한 조문에 가점을 주지 않는다). 별로 안 비슷한 질의의 인용 조문이 정답을 밀어내는 것을 줄인다.

### 1-6. 고시 번호 대신 이름·위치

```python
PIN_KEY_BY_NAME = [("의료급여", ("기준 중위소득", "4.")), ...]

def _gov(self, key):
    name_part, pos_part = key
    for e in self.ev:
        p = e["pos"].strip()
        if e["src"] == "고시" and name_part in e["name"] and (p == pos_part or p.startswith(pos_part + " ")):
            return e["id"]
    return None
```
- 1줄: 예전에는 `("의료급여", "G-0024")` 처럼 번호를 적었다. 고시 파일에 문단이 하나 추가되면 번호가 밀려 엉뚱한 문단을 고정하게 된다. 이제는 "고시 이름에 '기준 중위소득'이 들어 있고 위치가 '4.'로 시작하는 문단"으로 찾는다.
- 3~9줄: 고시 문단을 하나씩 보며 이름과 위치가 맞는 첫 문단의 번호를 돌려준다. 못 찾으면 `None`(고정하지 않음).
- 지금 파일(24문단)에서는 예전 번호와 똑같은 문단을 찾는다. 검색 결과 차이 0회로 확인했다.

### 1-7. 잠금 점검 모드 (`audit`)

```python
for r in read_csv(QNA):

        continue
    gold = gold_of(r)
    if not gold:
        continue
```

- 2~4줄: 묶음분할.csv 에 없는 묶음(잠금 묶음, 핵심이 아닌 묶음)은 건너뛴다.
- 5~7줄: 정답 조문이 없는 질의도 건너뛴다. `gold_of` 는 근거조문 칸에서 세 법령의 조문만 뽑는 함수.
- 8줄: 그 질의를 새 질문처럼 넣어 근거 8개를 찾는다. 자기 묶음(`skip_groups`)은 "비슷한 질의"에서 뺀다. 답을 미리 보고 찾는 것을 막기 위해서다.
- 10~12줄: 정답 조문이 위에서 3개, 5개, 8개 안에 하나라도 있으면 그 칸에 1을 더한다.

### 1-8. 2차 스위치 (nb_w, nb_norm, purpose, k_nb)

```python
for i in order[:c["k_nb"]]:
    if float(sq[i]) < c["nb_min"]:
        continue
    r = self.qa[int(i)]
    golds = gold_of(r)
    bonus = float(sq[i]) * c["nb_w"] / (max(len(golds), 1) ** c["nb_norm"])
```
- 1줄: 가점에 쓰는 비슷한 질의 수. 2차에서 5 → 10 으로 채택.
- 5줄: 비슷한 질의 하나가 주는 가점 = 그 질의의 유사도 × 배율(`nb_w`, 채택 0.5). `nb_norm` 은 인용 조문 수로 나누는 정도인데 버려서 0(나누지 않음)이다. `**` 는 거듭제곱.

```python
if c["purpose"] < 1.0:
    for j in total:
        if self.ev[j]["title"].strip() == "목적":
            total[j] *= c["purpose"]
```
- 조문 제목이 "목적"인 조문(대개 제1조) 점수를 0.5배로 낮춘다. 어느 질문에나 조금씩 비슷해서 자리를 차지하던 조문이다.

## 3. check_citations_v2.py (점검)

기존 check_citations.py 의 규칙은 `import` 로 그대로 가져와 쓰고(파일은 고치지 않음), 세 가지를 더했다.

```python
def is_intro(body):
    if re.search(r"\d", body) or ART_RE.search(body):
        return False
    return len(body) <= 40 and (bool(INTRO_RE.search(body)) or body.rstrip().endswith(":"))
```
- 2~3줄: 숫자나 "제N조"가 있으면 도입 문장이 아니다. `re.search` 는 글 안에서 무늬(정규식)를 찾는 함수, `\d` 는 숫자 한 글자.
- 4줄: 40자 이하이고, "다음과 같습니다·안내드립니다" 같은 표현이 있거나 쌍점(:)으로 끝나면 도입 문장. 이런 문장은 사실 문장 수에 넣지 않는다.

```python
years = set(YEAR_RE.findall(body))
eff = {y for i in ids if i[:2] in ("L-", "G-") for y in DATE_IN_ITEM.findall(items.get(i, ""))}
if years and eff and not (years & eff):
    year_warn.append(...)
```
- 1줄: 문장에 적힌 "20xx년"의 연도들.
- 2줄: 그 문장이 인용한 법령·고시(L-, G-)의 시행일자 연도들. 비슷한 질의응답(Q-)은 시행일자가 없어서 대조하지 않는다.
- 3~4줄: 둘 다 있는데 겹치는 연도가 하나도 없으면 연도경고. 연도경고가 있으면 판정은 "확인필요".

```python
if (draft or "").strip().startswith(HOLD_TEXT[:10]):
    return {..., "자동점검": "범위밖"}
```
- 초안이 보류 문구로 시작하면 판정을 "범위밖"으로 한다.

`python check_citations_v2.py test` 는 시험 문장 14개로 확인한다: 새 규칙과 상관없는 8개는 옛 점검과 판정이 같아야 하고, 새 규칙 6개는 의도대로 동작해야 한다. 규칙을 일부러 망가뜨렸을 때(도입 규칙 끄기, 연도 찾기 깨기) 시험이 실패하는 것도 확인했다.

```python
            or (isinstance(n, ast.FunctionDef) and n.name in ("fmt_date", "build_prompt"))]
```
- generate.py 를 통째로 불러오면 원래 폴더에 drafts/ 폴더를 새로 만든다. 그래서 `ast`(파이썬 코드를 구조로 읽는 표준 기능)로 필요한 세 부분(기존 SYSTEM 지시문, 날짜 바꾸는 함수, 프롬프트 조립 함수)만 꺼내 쓴다. 기준 초안이 기존과 같은 지시문·같은 조립 방식을 쓰도록 보장한다.

```python
SYSTEM_V6 = SYSTEM + "\n" + ADD_V6
```
- v6 지시문 = 기존 지시문 그대로 + 추가 규칙 9~12번(도입 문장 나쁜 예/좋은 예, 고시 우선, 일부만 답하기, 예시 답변 2건).

```python
def hold_reason(ret, q):
    if not in_scope_words(q):
        return "제도 판별 실패"
    s = top_sim(ret, q)
    if s < HOLD_SIM:
        return f"근거 유사도 {s:.3f} < {HOLD_SIM}"
    return ""
```
- 2~3줄: 질문에 세 제도와 관련된 말(FAM_WORDS + SCOPE_EXTRA)이 하나도 없으면 보류.
- 4~6줄: 질문과 가장 비슷한 법령·고시 문단의 유사도가 0.09 미만이면 보류.
- 보류되면 AI 를 부르지 않고 정해진 보류 문구(HOLD_TEXT)를 낸다.

```python
for var, ret, k_ev, system in (("기준", base, K_EV_BASE, SYSTEM), ("v6", v6, K_EV_V6, SYSTEM_V6)):
```
- 같은 질문으로 두 가지 프롬프트를 만든다. 기준 = 기존 검색(retrieve.py 와 같음) + 근거 5개 + 기존 지시문. v6 = 개선 검색 + 근거 8개 + v6 지시문.
- 시나리오 질문은 자기 묶음을 검색에서 뺀다(`skip_groups`).
- 점검에 쓰는 근거 글은 `prompts_items/` 에 따로 저장하고 하위 에이전트에게는 주지 않는다.

## 5. 재순위.py (3차)

```python
new = list(dict.fromkeys([i for i in got if i in ids]))
new += [i for i in ids if i not in new]
```
- 1줄: AI가 돌려준 순서(`got`)에서 원래 후보(`ids`)에 있는 번호만 남기고 중복을 뺀다. AI가 후보에 없는 번호를 지어내도 무시된다.
- 2줄: AI가 언급하지 않은 후보는 원래 순서대로 뒤에 붙인다. 그래서 20개 안에 정답이 들었는지는 재순위 전후가 같고(상한), 위쪽 순서만 바뀐다.
